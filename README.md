# Evaluacion_1_Programacion_3
Este proyecto corresponde a la **Evaluación 1 de Programación 3** de la Tecnicatura Universitaria en Programación (UTN). Consiste en la evolución de la plataforma **Food Store**, transformándola en una aplicación web desarrollada con HTML5, CSS3 y TypeScript, utilizando **Vite** como empaquetador de módulos y **pnpm** como gestor de paquetes.
